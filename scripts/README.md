# scripts 目录约定

只放**可执行入口**，不放业务逻辑。逻辑在 `src/dbas/`，脚本只做参数转发或一次性维护动作。

| 子目录 | 放什么 | 判定标准 |
|---|---|---|
| `demo/` | 合成数据卷生成器：不碰真实数据 | 只用于演示、冒烟、测试准备 |
| 项目根 | 抓包诊断等一次性运维工具 | 独立运行、与 CLI 无耦合 |

> 科研实验与绘图的入口脚本不在本仓，见 Hydroweave 实验仓的 `scripts/`。

## demo/

| 脚本 | 产出 |
|---|---|
| `make_demo_volume.py` | 最小合成卷（少量 NetCDF），给 CLI 冒烟用 |
| `make_demo_era_volume.py` | “类 ERA5”卷：全球网格、多层变量、三种坐标轴约定，给 subset 链路演示 |

## 抓包诊断（项目根）

| 脚本 | 说明 |
|---|---|
| `cds_capture_proxy.py` | CDS 请求抓包与脱敏分析，输出 Markdown 证据报告 |
| `cds_packet_capture.sh` | tcpdump 抓包包装，配合上一脚本定位下载链路问题 |

## 新增脚本时

1. 先判断属于上面哪一类，不确定就单独建目录并在此登记；
2. 业务逻辑写进 `src/dbas/`，脚本保持 20 行以内；
3. 用 `Path(__file__).resolve().parents[N]` 定位项目根，不要依赖调用时的 cwd；
4. 在本文件表格里登记一行。
